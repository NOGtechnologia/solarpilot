## ☀️ SolarPilot 1.0.0 – erste öffentliche Version

Open-Source-Dashboard für PV-Anlagen: Live-Energiefluss, 7-Tage-PV-Prognose, Börsenstrompreise,
Solar-News und konkrete Tipps – für SMA, Fronius, SolarEdge, Kostal, Huawei, Victron, Enphase, GoodWe,
OpenDTU, Shelly, MQTT und Home Assistant. Selbst gehostet, ohne Cloud-Zwang.

![SolarPilot Dashboard](https://raw.githubusercontent.com/NOGtechnologia/solarpilot/v1.0.0/docs/images/dashboard-dark.png)

### Schnellstart

```bash
docker run -d --name solarpilot --restart unless-stopped \
  -p 8080:8000 -v solarpilot-data:/data \
  ghcr.io/nogtechnologia/solarpilot:1.0.0
```

→ http://localhost:8080 öffnen, Admin-Konto anlegen, **„Demo starten“** oder eigene Anlage einrichten.
Das Image läuft auf **amd64** und **arm64** (Raspberry Pi 4/5, viele NAS).
Alternativ aus dem Quellcode: `git clone` + `docker compose up -d` – siehe [Installation](https://github.com/NOGtechnologia/solarpilot/blob/main/docs/installation.md).

### Highlights

- ⚡ Animierter Live-Energiefluss (Solar → Haus → Batterie → Netz), Updates per WebSocket
- 🏠 Beliebig viele Anlagen mit Summenansicht „Alle Anlagen“ und Einrichtungs-Assistent mit Karte
- 🔌 14 Adapter: Demo, SunSpec Modbus (SMA, SolarEdge, Kostal), Fronius, Huawei, Victron, Enphase, GoodWe, OpenDTU, Shelly 3EM, MQTT, Home Assistant
- 🌤️ PV-Prognose (Open-Meteo) mit lernendem Korrekturfaktor, DWD-Warnungen, Prognose vs. Ist
- 💶 Day-Ahead-Strompreise DE/AT (Energy-Charts, aWATTar) in 15-Minuten-Auflösung
- 💡 Tipps: Zeitfenster für Waschmaschine & E-Auto, „Batterie voll um …“, Minderertrag-Erkennung
- 📊 Tag/Woche/Monat/Jahr, Monatsreport als PDF, Ersparnis in €, vermiedenes CO₂
- 🔔 ntfy, Telegram, E-Mail · MQTT mit Home-Assistant-Auto-Discovery · installierbare PWA · DE/EN
